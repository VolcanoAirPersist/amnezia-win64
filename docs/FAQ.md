# FAQ

## Is this the official repository?

No. This repo mirrors **Windows portable** releases and documentation.
Official source code: [amnezia-vpn/amnezia-client](https://github.com/amnezia-vpn/amnezia-client).

## Why a `.zip` and not a single `.exe` in Releases?

Same layout as upstream Windows releases: one archive, program inside.

## Where is the source code?

In the upstream repository. This tree contains docs and release packaging only.

## Antivirus warnings?

Signed upstream builds are rare for portable tools. Download only from
**Releases** here. If unsure, compare file names with
[https://github.com/amnezia-vpn/amnezia-client](https://github.com/amnezia-vpn/amnezia-client).
